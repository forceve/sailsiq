# 三款桅杆支架设计审查

> 本文记录树状改版前的审查。连接与穿带结构的后续改进见 [树状支架全案](TREE_BRACING_DESIGN.md)；未改动的紧固、扣具和实体验证事项仍有效。

日期：2026-09-07。范围：Fareast23R、Fareast28R、J80 当前参数化模型；绑带—Bracing、Bracing—背板、背板—设备及整体结构。按工程塑料 3D 打印评估；涉及层间性能时以 FDM 为假设。透明压板仍按当前模型中的亚克力评估。

## 结论与证据边界

当前已完成桅杆外形适配和 3 mm 垫片的几何装配，但张紧、紧固和设备承托结构尚未形成完整工程设计。优先完成这些连接，再优化刚度、打印方向、轻量化和通用化。

本审查基于三份生成脚本、当前装配几何、实际设备外壳引用和制造商资料。已有实体连通、布尔检查、间隙和干涉检查只能证明几何关系，不能证明承载能力、抗滑能力或寿命。未进行 FEA 或实体载荷试验；设备含电池质量、真实重心、目标冲击工况和拆装频率尚未确定。以下“优先”指设计顺序，并不表示已预测零件必然失效。

## 1. 绑带与 Bracing

**优先补齐真实张紧和闭合机构。** 当前两条绑带是恒定截面的闭合环，魔术贴搭接只是参考方块，没有实际自由端、回折、扣具、有效搭接长度及锁紧行程。环在桅杆背侧还有约 5.3 mm 法向空隙，不能当作已预紧的装配状态。应选定实际织带与扣具，建立固定端、回折承载面、调整端和尾带收纳；核对湿态、戴手套和无工具操作。弹性和长期承载能力需按实际产品确认，不应从模型命名推断。

**改善穿带处的载荷传递和耐磨性。** 槽同时切入鞍座和 3 mm 连接板，受力转折位置被削弱。现有 0.25/0.35 mm 修边不能替代按织带弯折设计的圆滑承载面。建议槽端圆弧、局部加宽加厚、圆滑回折面，必要时采用可更换穿带件；搭接双层、缝线和扣具厚度纳入穿带空间。实际槽公差由打印试片与所选织带决定。

魔术贴应尽量受剪，避免自由端被剥开；剪切与剥离是不同载荷模式，不能直接互用产品额定值。[VELCRO 工作原理](https://www.velcro.com/news-and-blog/2023/02/how-do-velcro-brand-fasteners-work/)

保留两条独立绑带，并考虑独立防坠绳。防坠绳锚点不能与最薄穿带耳共用同一失效部位；带尾不得进入帆、索具活动路径。

## 2. Bracing 与背板

**优先增强转角和抗扭刚度。** 当前有效结构为鞍座、两片 3 mm 连接板与 3 mm 背板的融合，未实际加入连续三角加强筋或箱形抗扭结构。脚本中的过渡块函数及 fairing 参数不能当作已存在的加强结构。穿带槽进一步打断连接板连续性，按钮按压、侧向碰撞及振动会经这些转角传递。

建议在鞍座根部和背板交界增加渐变加强筋及较大根部圆角，在不挡穿带的区域形成折边、帽形或局部箱形截面。背板增加周边回边与局部筋，螺钉位置增加承力凸台。比统一加厚更值得先比较的是材料如何沿载荷路径连续分布。薄至 1 mm 的尾尖应复核其功能；若仅作外形收尾，应避免易磕碰、易分层的尖薄边；若作弹性功能件，则需单独定义材料与疲劳要求。

FDM 打印方向必须让主要拉力尽量沿连续路径传递，不能只用填充率评判强度。一体件在鞍座环向与背板弯曲方向之间可能存在打印方向冲突；分体打印可优化方向，但会增加紧固、装配误差和维护点。[Prusa 设计与打印方向指导](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)

增加绑带中心距可改善部分倾覆载荷分配，但当前 128 mm 高度和 31.4 mm 槽高限制了端部余量。不能仅将 68 mm 中心距拉大，必须同时检查总高度、槽端余料与根部连接。

## 3. 背板与设备

**首先补齐紧固硬件。** 六个孔均为 Ø3.4 通孔，螺钉只是圆柱外形参考，尚无螺母、嵌件座、可靠螺纹配合及明确长度。不能把 3 mm 平板视作已有 M3 螺纹连接。应选定热熔嵌件或防转捕获螺母，设计相应局部凸台、孔形、边距、安装和工具空间，定义防松与可更换方式。嵌件孔与凸台按具体型号设计。[SPIROL 嵌件孔设计](https://www.spirol.com/resources/white-papers/how-to-design-the-proper-hole-for-heat-ultrasonic-inserts/)

**让机械承托承担设备重量。** 当前主要靠压板夹紧后的摩擦固定，没有明确底托与侧向定位。建议底托承受下滑载荷、侧挡限制横移、上扣限制脱出，压紧只负责防晃。加入硬限位柱或套筒，防止拧紧量任意改变设备夹持间隙；软垫用于防响和吸收公差。承托、夹紧力应落在外壳结构边框，避免经粘接面板、屏幕或按键传力。

**透明件不宜兼任主要预紧承载框。** 开窗版压板沉孔下剩余 1.9 mm，孔中心距外边 7 mm、沉孔半径 3.5 mm，局部剩余边料较窄。实际是否开裂取决于材料、加工、扭矩与冲击，当前不能判定强度合格。更稳妥的方向是独立结构压框，并使透明件只承担防护功能；如保留现结构，应设计垫圈/肩套、适当孔隙、去毛刺和受控压紧，核对热胀冷缩。制造商的板材点固定建议提供原理参考，不应机械套用为本产品唯一尺寸标准。[ACRYLITE 孔边距与点固定指导](https://www.acrylite.co/resources/knowledge-base/article/how-far-in-should-I-drill-a-hole-from-the-edge-of-acrylic-sheet?category=working-with-acrylite-r)

六颗螺钉适合低频拆卸。若需经常取设备充电或收纳，可改为带底托的导入结构和少量防脱紧固件/可靠锁扣，并保留二次防脱；不能只删掉现有螺钉。当前实际外壳引用下，玻璃和按键未与压板发生静态实体重叠，但这不证明戴手套可操作，应加入手指、工具与插拔线缆空间检查。

## 4. 整体结构、材料和海上使用

**3 mm 垫片还需要工作状态定义。** 3 mm 自由垫片放入 3 mm 间隙，名义上没有压缩；真实张紧后鞍座和带路会变化。需确定实心/发泡、硬度、压缩载荷、压缩永久变形及湿态摩擦，联动确定工作厚度、打印误差和张紧范围。可用 t_work = 3 × (1 − ε) 描述，但 ε 必须由实际材料和试验确定；不能将某种泡棉的推荐压缩率直接用在未选型的硅胶上。[Rogers 压缩力—变形说明](https://rogerscorp.com/blog/2024/the-ultimate-guide-to-compression-force-deflection-free-tool)

垫片可加入圆滑定位边或机械捕获结构，防止沿桅杆窜动；做排水路径、消除积盐盲腔，并确保可拆换。降低设备外伸有助于降低部分弯矩，但须保持手指、扣具和设备维护空间。载荷计算应使用实测质量与重心，分别考虑重力、船体加速度、按键按压和偶发碰撞；当前几何中心距离不能代替所有工况的力臂。

**核对帆槽活动空间。** 当前支架和设备布置在模型 +Y 帆槽侧。如果实际安装高度有帆边、滑块或索具经过，需要调整朝向或设计避让；若位于不经过这些部件的位置，结论可能不同。需用实际安装高度和运动包络确认，不能仅凭静态桅杆无干涉判断可用。Fareast 对应实际型材仍需 Mast ID 或现场截面核对。

**罗盘性能是结构约束。** 外壳设计已标出磁敏感参考区；新增螺母、嵌件、扣具和防脱结构时，应特别避免磁性锁扣，并核对紧固件实际磁性与距离。项目 R20 只是参考区，不是经实测保证的通用安全半径。不锈钢名称也不等于零磁干扰。安装、拆装和更换硬件后，应比较整机航向偏差与重复性；铁磁材料可导致硬铁/软铁误差。[NXP eCompass 校准说明](https://www.nxp.com/docs/en/application-note/AN4246.pdf)

ASA 可作为户外 FDM 候选，其耐 UV 和耐温特性有制造商说明，但仍需针对实际打印件验证蠕变、冲击与层间强度。PA、PC 或填充材料应按具体牌号的吸水、UV、打印方向及长期性能选型，不能仅凭“工程塑料”名称确定壁厚。[Prusa ASA 材料说明](https://help.prusa3d.com/article/asa_1809)

进一步可采用三种船型专用鞍座、共用设备承托框和耗材的模块化方案。收益是维护和改型方便，代价是新增连接、误差及松动点；优先在接口可靠后实施。

## 建议迭代与验证

1. 先确定实际绑带/扣具及紧固件，建立固定端、张紧行程、机械底托与二次防脱，并核对帆槽侧的真实安装空间。
2. 再做根部加强、背板回边、嵌件凸台、硬限位和垫片压缩/定位，按所选工艺确定打印方向和公差。
3. 通过实体装配和载荷验证后，再做模块化、快拆、减重和外形收敛。

| 验证 | 要回答的问题 |
| --- | --- |
| 短段型材配合样件、穿带槽及嵌件试片 | 三款轮廓是否贴合，实际织带能否穿装，嵌件能否可靠安装 |
| 干态与湿态轴向拉滑、绕桅杆扭转 | 预紧后是否滑移，航向是否产生不可接受的变化 |
| 背板边缘加载、设备按键反复操作 | 局部挠度、回弹和根部应变是否满足要求 |
| 长时间预紧并经历目标温度环境 | 塑料/硅胶松弛后是否仍能保持定位，是否需要复紧 |
| 实际载荷谱的振动、冲击、反复拆装 | 层间裂纹、槽边磨损、紧固松动、锁扣寿命和防脱是否可靠 |
| 湿手/手套装拆、冲洗、排水检查 | 操作能否完成，是否易遗失零件、积水积盐或勾挂索具 |
| 安装前后及拆装后的罗盘对比 | 五金和安装重复性对航向性能的影响 |

载荷值、循环数、允许位移和航向变化限值应在设备总质量、使用工况和产品精度目标确定后写入 specs。本轮不设未经验证的载荷额定值，也未修改三款模型结构。

## 模型维护事项

- 清理旧 apex/fairing 参数及未接入的过渡块函数，避免图纸或人工审查误读为实际结构。
- 实际设备导入失败时不应静默退回简化占位体并继续作为正式装配验证；应明确标识参考模式或让验证失败。
- 后续导出同时保留自由态和张紧工作态，以及紧固件、垫片和绑带 BOM，避免只有视觉环路而没有实际装配定义。
