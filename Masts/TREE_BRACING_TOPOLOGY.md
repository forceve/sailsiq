# V2 实施与拓扑优化评估（历史记录）

当前模型为 V3，见 [V3 节点设计与对比](TREE_BRACING_V3_NODES.md)。以下结果和“最终 V2”均指已冻结的 V2，不代表当前 V3。

2026-09-08。结论：采用外缘直连、沿鞍座展开的低凸根部和较充足的分支截面。优先继续参数化形状优化；局部拓扑优化技术上可行，但尚未执行 BESO/SIMP 材料迭代，也没有证明当前形状是最优解。

## 已实施的取舍

三款均以连续鞍座承接左右根部，四个分支长段融入真正的面板外缘 X = ±83 mm，外宽保持 166 mm。边缘向内分配加强截面，内侧实际建出 R2 过渡。硅胶厚度保持 3 mm，面板和设备站位不变，主体不切穿绑带槽。

根部沿鞍座曲线延伸，由低凸基部渐变成椭圆主干；主控制截面由 V1 的 12 × 24 改为 10 × 26 mm。J80 在中高 Z=600、Y=6/18 mm 的横向投影外凸量，分别由约 7.00/8.79 降到 3.73/4.70 mm。这是指定截面的 X 方向测量，不是整个根部的最大法向凸出量。其他两款结果相近，原始测点保存在几何报告。

试过 8 × 12 mm 中段的细分支候选，整体减料约 3.8%，但 J80 初步分析明显变软，故不作为交付方案。最终中段采用 10 × 14 mm，其他控制站渐变；最高三次放样改善了交换文件的稳定性。最终方案的全件实心体积与树状 V1 接近：

| 船型 | V1 cm³ | 最终 V2 cm³ | 相对 V1 |
| --- | ---: | ---: | ---: |
| Fareast23R | 193.543 | 193.893 | +0.18% |
| Fareast28R | 203.670 | 205.080 | +0.69% |
| J80 | 196.797 | 197.755 | +0.49% |

因此本次收益是较低的根部凸出量、外缘连接与刚度分配，而不是相对 V1 继续显著减重。与更早的开槽连接板全件相比仍减少约 1.8%–2.2% 体积。实际切片重量还受填充和支撑影响。

候选绳路包络仍为 24 × 20 mm，V2 相对 V1 向外移 3 mm。三款包络与绑带净距分别约 2.63、3.66、6.31 mm，与支架均至少 2 mm。这个移动是待实船确认的设计假设，不能理解为实际绳索已经改道；尤其 J80 松绳扫掠仍须现场检查。

## 实际运行的有限元比较

本机已跑通 Gmsh 4.15.0 → CalculiX 2.22，分析对象仅为 J80。比较了 V1、被放弃的细分支候选和最终 V2；三个方案均采用 4 mm 与 3 mm 两档网格。另有一次加厚分支的中间验证，不作为最终量化依据。

统一假设如下：

- 单位为 mm、N。参考线弹性各向同性材料 E=1000 MPa、ν=0.35；这不是 ASA、PA 或某种打印材料的实测属性。所有方案用同一 E 比较柔度。
- 固定鞍座内侧两条 Z 中心 600±34、宽 30 mm 的参考接触带的三个平移自由度。采用边界网格节点与 3 mm 偏置桅杆曲线距离小于 0.08 mm 的节点识别。这是理想化刚性带状支承，未模拟硅胶、绑带预紧、摩擦、接触脱离或真实绑带端部。
- 在设备承托前平面 Y=90.3 mm、约 132×98 mm 的区域分布载荷。按表面三角形面积及二次三角形一致节点载荷分配，避免单节点点载荷；边界按三角形重心筛选，实际受载面积见 setup JSON。
- Fx、Fy、Fz 各 1 N；绕桅杆 Z 轴施加 100 N·mm 力偶，合力为零。局部坐标含义分别为左右、面板法向、沿桅杆。载荷由离散网格分配，存在小的非目标力矩，已记录在 setup JSON，方案间使用同样方法。
- 采用直边二阶 C3D10 四面体。初次把中间节点投到曲面上会出现倒置单元，未使用该网格；改为直边二阶近似，并检查所有单元角点有向体积为正。对这种直边单元，该检查也排除了负 Jacobian。
- 比较量为柔度 F·u（N·mm），越低表示同一载荷下整体更硬；应变能为其一半。每个工况核对总反力误差 <1e-4 N、总反力矩误差 <1e-3 N·mm。求解日志无 ERROR/WARNING。

精细档结果及两档差异见下表；扭转载荷幅值不同，不能直接跨行比较柔度数值大小。

| 工况 | V1 柔度 | 最终 V2 柔度 | V2 相对 V1 | V1 / V2 从 4→3 mm 的变化 |
| --- | ---: | ---: | ---: | ---: |
| Fx | 0.115258 | 0.086767 | -24.7% | -2.8% / -2.5% |
| Fy | 0.061456 | 0.051054 | -16.9% | -2.7% / -1.1% |
| Fz | 0.073543 | 0.055079 | -25.1% | -7.6% / -4.6% |
| Mz | 0.072297 | 0.062086 | -14.1% | -2.8% / -1.3% |

这些结果支持“较厚分支比单纯压小根部更合适”的初步排序。这里同时改变了根部、分支与面板端，不能将全部改善单独归因于消除 T 形节点。

## 数值结果的限制

最终精细网格为约 14.9 万节点、7.56 万四面体。仍有约 500 个形状质量较差的四面体警告，集中处理这些小边/细长单元属于下一轮分析工作；没有倒置单元不等于网格完全合格。网格体积相对 CAD 约少 0.5%–0.7%，来自曲面的直边近似。

两档下方案排序相同，但 V1 沿桅杆工况柔度改变约 7.6%，最终 V2 该工况约 4.6%。因此只能称为初步网格敏感性比较，不能宣称已完全收敛。表中的百分比是模型结果，不是预测实船刚度提高的精确值。

没有输出或采用局部应力峰值作强度判断，也没有分析疲劳、蠕变、屈曲、碰撞、大变形和层间开裂。刚性带状约束会低估真实装配的柔度；在材料和接触未经校准前，不把单位载荷线性放大成额定承载能力，也不把 J80 排序直接推广为另两款结构验证。

## 下一步优化路线

| 路线 | 可执行做法 | 收益与取舍 | 优先级 |
| --- | --- | --- | --- |
| 参数化形状优化 | 扫描根部宽/高、埋入与展开长度、分叉位置、中段椭圆长短轴、末端渐变长度及内圆角 | 当前流程已验证可行，容易保留带路与绳路；先找等体积下多方向柔度较低的方案 | 最高 |
| 局部拓扑优化 | 用 Gmsh/CalculiX 和 BESO，在根部至外缘间建立比现有细枝更宽的设计域；冻结接口和禁入空间 | 可以检验是否需要斜撑、扭转闭环或不同分叉位置；需要另行配置 BESO、验证过滤和制造约束 | 后续可行 |
| 全件拓扑优化 | 同时开放鞍座非接触区和面板背部材料分布 | 减料空间更大，但必须引入接触压力、设备承托、六孔载荷及打印约束，工作量明显增加 | 暂不优先 |

参数化下一轮建议把总 CAD 体积控制在 V1 的约 101% 以内，以四个方向相对 V1 的柔度形成 Pareto 比较，不先人为给未知工况分配精确权重。根部宽 10–12、主干高 24–28、中段宽 8–12/高 12–18 mm 可作为搜索起点；这些是候选范围，所有组合必须重新通过带路、净空、连接和制造检查。

局部拓扑优化的非设计区应包括：3 mm 垫片贴合面及连续鞍座、两条带路和定位条、实际设备承托面、六孔及其必要边距、面板外缘连接界面。两侧候选绳路及松绳余量为禁入区。可变区覆盖根部、四分支与边缘过渡周围，允许材料重新连接，不能只在已经很细的四根杆内挖洞。

先设可打印最小构件尺度，再定网格。拓扑设计域可从约 6 mm 最小承力构件假设起步，局部网格约 2 mm 或更细，并另做敏感性验证；最终尺寸仍由载荷和打印试片确定。材料分布结果必须重建为有圆角、可排支撑的 CAD，再重算。工程塑料 FDM 的打印方向、层间性能和悬垂不能用各向同性 BESO 自动解决。[Autodesk 最小构件尺寸](https://help.autodesk.com/cloudhelp/ENU/Fusion-Simulate/files/MIN-MEMBER-SIZE-CONCEPT.htm)、[Prusa 打印方向与设计](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)

开源 BESO 路线有现成项目，但本轮仅跑通前端网格和线弹性求解，没有完成优化器安装与迭代验证。商业替代可使用 Fusion Shape Optimization，并同样执行保留区域、重建与应力复核。[CalculiX BESO](https://github.com/calculix/beso)、[Fusion 官方流程](https://help.autodesk.com/view/fusion360/ENU/?contextId=SIM-SHAPE-OP)

## 可期待的减重量级

J80 最终全件约 197754.7 mm³；扣除连续鞍座、定位条和承托板后，独立连接区域约 39345.6 mm³，占约 19.9%。这避免重复计算融合重叠体积。若仅此区域再减 10%、20%、30%，且其他部分不变，全件的算术减量约为 2.0%、4.0%、6.0%。这不是可实现减重预测；要保持刚度、最小杆径和层间可靠性，未必能达到这些档位。

当前有依据的收益是以接近 V1 的材料量降低初步柔度，并收小根部凸出。继续拓扑优化最值得回答的是能否在保留这一刚度的条件下减回少量连接材料，而非预设全件再轻 20%。真实设备质量/重心、按键与碰撞载荷、打印材料方向参数和 J80 绳路实测是进入承载定型前最重要的输入。

## 文件与复现

几何源为 `tree_bracing.py`，V1 冻结于 `cadquery_out/tree_v1`。分析源为 `compare_tree_fea.py` 与 `summarize_tree_fea.py`。`cadquery_out/fea` 内 `v1.brep` 是基准，`v2.brep` 是未采用的细分支，`v2_final.brep` 对应交付模型。每个 setup JSON 包含网格、载荷合力/力矩与警告；results JSON 包含柔度、能量、位移及平衡复核，comparison JSON 为汇总。

在相同依赖环境中运行：

```powershell
python Masts/compare_tree_fea.py v1 --size 4
python Masts/compare_tree_fea.py v1 --size 3
python Masts/compare_tree_fea.py v2 --size 4
python Masts/compare_tree_fea.py v2 --size 3
python Masts/compare_tree_fea.py v2_final --size 4
python Masts/compare_tree_fea.py v2_final --size 3
python Masts/summarize_tree_fea.py
```

本机求解器路径在脚本中明确配置为 `E:/FreeCAD_1.1/bin`。异机需修改路径；并行网格可能出现细微离散差异。[Gmsh 官方网格与文件文档](https://gmsh.info/doc/texinfo/gmsh.html)
